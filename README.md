# Employee Power BI Dashboard

## Project Overview

An interactive employee data dashboard built with Microsoft Power BI to analyze employee information and present key insights through interactive visualizations.

## Tools & Technologies

* Microsoft Power BI
* Microsoft Excel
* Data Analysis
* Data Visualization

## Dashboard Features

* Employee distribution analysis
* Department analysis
* Salary analysis
* KPI cards
* Interactive charts
* Pivot tables
* Slicers for interactive filtering
* Data filtering and aggregation

## Key Skills Demonstrated

* Data Analysis
* Data Visualization
* Dashboard Development
* Microsoft Power BI
* Microsoft Excel
